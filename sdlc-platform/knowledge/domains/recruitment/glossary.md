# Recruitment: domain glossary

Agents use this glossary for shared vocabulary. It is **not** a source of requirements.

| Term | Meaning |
|---|---|
| Requisition | An internal request to hire for a role: department, headcount, budget, justification. It needs approval. |
| Opening / job posting | An approved requisition published so that candidates can apply. |
| Candidate / applicant | A person applying or sourced for an opening. One candidate can apply to several openings. |
| Application | A candidate's link to one opening, with its own pipeline stage. |
| Pipeline / stage | The ordered hiring steps, e.g. Applied → Screening → Interview → HR → Offer → Joined. |
| Scorecard | An interviewer's structured feedback: ratings per competency plus a recommendation. |
| Offer | A proposed role, CTC and joining date. It may need approval, and is accepted, declined or withdrawn. |
| CTC | Cost to company: the total annual compensation. |
| Referral | A candidate submitted by an employee, sometimes with a bonus. |
| Time-to-hire | The time from requisition approval (or application) to offer acceptance. |
| Source | Where the candidate came from: careers page, job board, referral, agency. |

## Typical roles
Recruiter, hiring manager, interviewer, HR/admin, approver (finance or department head), and the candidate as an external user.

## Typical feature set (for orientation only, not requirements)
- Requisitions and approval
- Job postings
- Candidate intake and duplicate handling
- Pipeline
- Interview scheduling and scorecards
- Offers and approval
- Onboarding handoff
- Candidate communication
- Referrals
- Hiring analytics
- Data retention
